# KOTOBA N5

Ứng dụng học tiếng Nhật trình độ sơ cấp N5, với giao diện tiếng Việt.

## Tính năng

- Học Hiragana và Katakana, gồm âm cơ bản, âm đục và âm ghép.
- Luyện nhận diện Kana theo hai chiều và lưu kết quả cần ôn trên thiết bị.
- Học 25 bài theo năm phần: từ mới, ngữ pháp, luyện đọc, luyện viết và bài tập tổng hợp.
- Lưu tiến độ học trong `localStorage`; ứng dụng không gửi dữ liệu học lên máy chủ.

## Chạy ứng dụng

Yêu cầu Node.js 20 trở lên. Ứng dụng không cần cài thư viện bên ngoài.

```sh
npm run dev
```

Mở <http://localhost:4173> trong trình duyệt.
